## Production URL

**productionUrl:** https://markovada.github.io/LandingPageDemo/

Сайт публикуется на GitHub Pages при push в ветку `master` (workflow [Deploy to GitHub Pages](.github/workflows/deploy.yml)).

## Локальный запуск

```bash
python -m http.server 8080
```

Откройте http://localhost:8080/

Можно также открыть `index.html` в браузере (для шрифтов Google нужен интернет).

## Стек

- HTML, CSS, JavaScript (без сборщика)
- Деплой: GitHub Actions → GitHub Pages
